# Idea bank

Explored directions that are deliberately **not** in the current build. They
live here so future work can pick them up without re-running the discovery.

- **Living Lobby.** The first visual-direction run's concept: the site as a
  live room. Retired when the Ember Hours direction was picked; revisit only
  if the community asks for a denser live surface.
- **Recommended mix.** The blind re-run's synthesis of both runs. Parked in
  favour of building Ember Hours in full with no mix.
- **Runner-up concepts.** Concepts A and B from both visual-direction runs.
  Mine them for components (cards, rails, glyphs) rather than reviving them
  whole.
- **Light theme.** The token file keeps override hooks and `color-scheme`
  can gain a light set later without touching components. Needs its own
  contrast pass over every pair in `tokens/contrast.json` first.
